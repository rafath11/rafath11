# Contributing

Issues and pull requests are welcome on any of the tool repos.

- For bugs: open an issue with what you ran, what you expected, and what happened.
- For ideas: start a Discussion first — if it fits the ITAM/SAM/CMDB scope, it may become a build.
- Keep contributions focused and small; explain the 'why' in the PR description.

Thanks for helping keep these tools honest and useful.
